Introduction to Census Data

US Census Data provides vital and extensive insights by providing widely used demographic and economic data about the United States. (U.S. Census Bureau 2026d)

Why US Census Data Matters

Insights provided by Census data

  • Population counts across states and local areas
  • Demographic information: Age and aging trend, household structures, migration patterns
  • Economic Information: poverty measures, income levels, economic activity
  • Housing and Infrastructure: housing prices, housing occupancy/vacancies, heating sources

Uses for these insights

  • Politics: redistricting, informing policy
  • Business: Choosing location, understanding customer patterns
  • Community services: Information for planning community services such as where to provide services for the elderly and whether to build new roads/schools
  • Government: Informs policy decisions concerning neighborhood improvements, public health, education, transportation and more.

Main Datasets provided by the U.S. Census Bureau

There are many data sets provided by the U.S. Census Bureau but the main ones are as follows (U.S. Census Bureau 2026b):

  • Decennial Census: Counts every resident every 10 years to determine political representation
  • American Community Survery: Gathers annual and monthly social, economic, and housing data for local communities
  • TIGER/Line Geodatabases: databases with information about spacial deliniation on the national and state level (U.S. Census Bureau 2025a)

Accessing Census Data

Main ways to get Census Data

There are a couple options on how to download U.S. Census Data. These are the main methods:

  • data.census.gov: you can download many tables manually online, TIGER files are also here
  • Census API: preferred method because it allows for direct programmic access, makes this ideal for programmers and researchers. (U.S. Census Bureau 2026c)
  • QuickFacts: streamlined tool that provides frequently requested statistics for states, counties, cities, and towns.
  • Python and R Packages: data is occasionally available in this way.

Why Use the API

As previously stated, the API is more streamlined and allows for importing data using the command line, which is ideal for programmers. (Patton 2025)

Using the API ultimately makes your code:

  • more reproducable
  • more efficient
  • effective for larger workflows

How to Use the API

  1. Choose the U.S. census data set (i.e. the ACS) (U.S. Census Bureau 2026a)
  2. Choose which variables you need and find the alphanumeric code for them
  3. Request an API key
  4. Build your API URL (example URL: http://api.census.gov/data/2023/acs/acs5?get=NAME,B01003_001E& for=state:*&key=127522bb146effe5374s61fd4279c26a4571503) (example key, not usable) (U.S. Census Bureau 2025b)
  5. Request the data: use requests package (response = requests.get(url)) (PyPI 2026)
  6. Create a data frame to use the data

How to keep API key hidden

  • While an API key is not as sensitive as something like a password, you want to avoid other people using your key for their requests as your key can be revoked if its misused
  • One method is to use a .env file to store your key as an environmental variable. (make sure .env is ignored by git).
  • In your .env file, save your key as a variable and then load it into your python environment.
  • Example of what your .env file could look like (fake key):
CENSUS_API_KEY=127522bb146effe5374s61fd4279c26a4571503
  • When collaborating, collaborators need to create their own .env file with their own key, making sure the file is not committed. As long as they do this and follow the syntax, the process is reproducable.

How to keep API key hidden (cont.)

import os
from dotenv import load_dotenv

# Find the repository-level .env file without replacing existing variables.
load_dotenv()
api_key = os.getenv("CENSUS_API_KEY")
if not api_key:
    raise ValueError("Add CENSUS_API_KEY to your local .env file.")
  • In your code, your API URL will look like url = f"https://api.census.gov/data/2023/acs/acs5? get=NAME,B01003_001E&for=state:*&key={api_key}"

Example 1: Population By State Data Frame

# Importing necessary packages
import requests
import pandas as pd

# API URL 
url = f"https://api.census.gov/data/2023/acs/acs5?get=NAME,B01003_001E&for=state:*&key={api_key}"

response = requests.get(url)
data = response.json()

Converting the data into a data frame

# making data frame
df = pd.DataFrame(data[1:], columns=data[0])

# Making population numbers into integers
df["B01003_001E"] = df["B01003_001E"].astype(int)

# Making columnn names more readable
df = df.rename(columns={
  "NAME" : "State",
  "B01003_001E" : "Population"
})

# Removing the non-states included
df = df[~df["State"].isin(["Puerto Rico", "District of Columbia"])]

# Keeping only state names and population numbers and 10 entries
df = df[["State", "Population"]].head(10)

Spatial Census Data

Importance of Spacial Census Data

Considering spacial census data is helpful for many things including:

  • Making choropleth maps
  • Regional comparisons
  • Policy analysis relative to location

Spacial census data is powerful because you can consider many different scales, from the national scale to census blocks, which can be as small as a city block in urban areas.

Spacial Example

Choropleth Map of Internet Access

import matplotlib.pyplot as plt
import geopandas as gpd
import requests
import pandas as pd

url = f"https://api.census.gov/data/2024/acs/acs5/subject?get=NAME,S2801_C02_012E&for=state:*&key={api_key}"

response = requests.get(url)
data = response.json()

Data Frame

# Making DataFrame
df = pd.DataFrame(data[1:], columns=data[0])

# Convert internet access percentage to numeric
df["Internet Access"] = df["S2801_C02_012E"].astype(float)

Spacial Data

# Downloading state boundaries from TIGER
states = gpd.read_file(
    "https://www2.census.gov/geo/tiger/GENZ2024/shp/cb_2024_us_state_500k.zip"
)

# Match Census state codes
states["STATEFP"] = states["STATEFP"].astype(str)

df["state"] = df["state"].astype(str).str.zfill(2)

# Merge the Census data with the map
map_data = states.merge(
    df,
    left_on="STATEFP",
    right_on="state"
)

# Remove Alaska, Hawaii, and Puerto Rico for cleaner map
map_data = map_data[
    ~map_data["STUSPS"].isin(["AK", "HI", "PR"])
]

Conclusion

The U.S. Census Bureau provides a wide range of demographic, economic, and geographic data that can be used in numerous fields to understand communities and populations.

Using the Census API is the best option for accessing Census data for programmers. Accessing data using the API allows programmers to:

  • Create dataframes
  • Create statistical visualizations
  • Create maps with statistical insights

The Census API makes large amounts of public data accessible, reproducible, and useful for data-driven research.
