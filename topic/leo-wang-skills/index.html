Where does a skill fit?

Part In our teaching-assistant example
Agent The assistant doing the work
Prompt “Explain the code line by line”
Tools Python, a terminal, and file access
Skill A reusable guide, with optional supporting files

Skill structure: OpenAI (n.d.).

What is inside a skill?

Start with a file called SKILL.md:

---
name: explain-small-code
description: Explain short Python examples.
---

Explain each line in simple language.
Show the result and one way to check it.

Top: name and description. Below: instructions for the agent.

Optional folders: references/, scripts/, and assets/.

Structure: OpenAI (n.d.). Short teaching excerpt.

How an agent uses the guide

  1. The agent sees the skill’s name and short description.
  2. You ask for the skill, or the agent picks it for the task.
  3. It opens the instructions and any files it needs.
  4. It follows the steps and uses the tools available to it.

Then check: did it actually do what you asked?

Skill selection: OpenAI (n.d.). This describes the Codex example; product details can differ.

What did the coach say?

Selected excerpts from the recorded response:

This code starts with a list of numbers, keeps the numbers that pass a condition, and calculates their average.

Only 8 passes, so kept becomes [8].

The denominator is the number of retained entries, not the original four entries.

With >= 4, both copies of 4 count: filtering does not remove duplicates.

Saved response from one explicit invocation in Codex, formatted as an excerpt for reading.

Check next: run the calculation and try changing the filter.

Learning Coach: check your understanding

Try a variation: What changes if we use >= 4?

This Python check verifies the numbers in the recorded answer.

values = [0, 4, 4, 8]
kept = [x for x in values if x > 4]
mean = sum(kept) / len(kept)
print("Strict > 4:", kept, "mean =", mean)
inclusive = [x for x in values if x >= 4]
print("With >= 4:", inclusive)
print("New mean:", round(sum(inclusive) / len(inclusive), 3))
assert values == [0, 4, 4, 8]
Strict > 4: [8] mean = 8.0
With >= 4: [4, 4, 8]
New mean: 5.333

Changing the filter changes what goes into the average.

Set up the 7 a.m. routine

First, run once and check the brief. Then connect:

  • Access: web tools for news; a mailbox connector for Inbox Brief.
  • Saved progress: a file or database for confirmed task status.
  • Scheduling: a host scheduler set to 7 a.m., America/New_York.
  • Delivery: an app destination, or email access and permission to send.

The skill supplies instructions. These connections must be configured in the host separately.

For planning, confirm yesterday’s progress before updating today’s tasks. If no answer arrives, mark progress unknown and ask again.

Next: check whether each run follows the instructions.

How would you test a skill?

Test What to check
A small known case Does the answer match independent evidence?
Missing information Does it identify the gap instead of inventing facts?
An unrelated request Does the host avoid selecting the wrong skill?
A repeated run What changes, and are the changes acceptable?

Read the answer and check whether it does what you asked.

When a skill is worth using

Use a skill when you keep giving the same instructions for the same kind of task.

For a one-time question, a prompt may be enough.

For a fixed calculation, a script may be enough.

Old instructions and wrong assumptions can get repeated too.

Example: a deadline moves

Old email: Nov 20 → New email: Nov 23.

Use the updated deadline, then revise the plan.

Take away: write it once, reuse it, check it

Step What you do
1. Pick a recurring task Explain code, sort emails, or follow news
2. Write the guide Define the input, steps, and expected output
3. Try one small case Check the result against something you know
4. Keep it current Update sources, dates, and instructions

A skill reuses your process. You still check the result.
